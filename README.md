# CSS - Laundry Services Hero Section

## Project Description
A responsive web application Hero Section and Navigation bar designed for a laundry service built using HTML5 and CSS3[cite: 1, 2].

## Features
* Navigation bar including a logo on the left, inline navigation links (Home, Services, About Us, Contact Us), and username on the right[cite: 1].
* Hero section consisting of two divs containing a heading, description text, "Book a Service Today" button, and an illustration/image.
* Designed with Viewport units (`vh` and `vw`) to fit the entire section perfectly on the screen without vertical scrolling.
